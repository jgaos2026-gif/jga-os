About jga-os

A browser-based OS concept built with passion.

The Project

jga-os is an open web experiment that reimagines what a desktop OS could look like entirely inside a browser tab. It ships as a single static page — no server, no framework, no build step required.

The Creator

jaysgraphicarts-ai blends graphic design sensibilities with modern AI-assisted development to build sleek, functional interfaces that push the web forward.

Tech Stack

  • HTML5 — semantic markup
  • CSS3 — custom properties, grid, glass-morphism
  • Vanilla JavaScript — no frameworks
  • GitHub Pages — live hosting
